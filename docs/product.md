# Product contract

GuideKit is a company-configurable visual and voice assistant platform for websites. Developers upload company knowledge, configure an agent and permitted capabilities, publish an immutable version, and embed one shared SDK using an agent ID. The website visitor can ask questions, get anchored highlights and explanations, and approve registered actions.

Company knowledge uses retrieval, not model fine-tuning. Page context supplies bounded live UI information. Guidance can discover accessible controls; reliable mutations require host-registered functions and outcome checks. Web only in the first version. No claim of arbitrary-site full automation.

Core acceptance: real login and persistent tenant data; two tenant isolation; knowledge upload/text entry; draft/publish; install snippet; same SDK on CRM and a second independent site; real subscription inference; evidence citations; anchored visual guidance; confirmation and verified host action; session history; restart persistence; missing-target and cancellation recovery. Cutroom is the intended editor host and uses its existing command/revision boundary.

Later scope: richer animations, workflow graph/TigerGraph, Wispr voice API subject to approved access, billing, hosted commercial inference, native adapters. Browser voice can be offered with explicit browser support and permission handling; no provider integration is claimed without credentials and a live request.
